# ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ramya-portfolio.git
```

Move into project folder:

```bash
cd ramya-portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

# 🏗️ Build Project

```bash
npm run build
```
